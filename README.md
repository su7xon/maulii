

# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/ae38b8f6-717f-4244-b406-bf55456fa3df

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `VITE_GROQ_API_KEY` in `.env` to your Groq API key (get one free at https://console.groq.com)
3. Run the app:
   `npm run dev`
